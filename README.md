# Inventory Application

A full-stack inventory management application built with **Node.js, Express, EJS, and PostgreSQL** as part of [The Odin Project](https://www.theodinproject.com/).

## Features

* View inventory items and categories.
* Create, edit, and delete items and categories.
* Manage item quantities, prices, and descriptions.
* Validate user input.
* Store inventory data in PostgreSQL.
* Responsive design for desktop and mobile screens.

* Express.js

## Getting Started

### Prerequisites

* Node.js and npm
* PostgreSQL

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/RunTheLi/Inventory_Application.git
   cd Inventory_Application
   ```

2. Install dependencies:

   ```bash
   npm install
   ```
3. Initialize the project (if needed):

   ```bash
   npm init -y
   ```
4. Initialize the project (must):

   ```bash
   npm install express-validator
   ```
   ```bash
   npm install ejs
   ```
   ```bash
   npm install pg
   ```

5. Create a `.env` file and configure your PostgreSQL connection settings.

6. Set up the database tables and configure your database connection.

7. Seed the database with sample data:

   ```bash
   npm run seed
   ```

8. Start the application:

   ```bash
   npm start
   ```

9. Open `http://localhost:3000` in your browser.
